## Ejecución

Para iniciar la aplicación y que se vea todo en orden, hay que ejecutar desde la terminal app.py.
Y hay que ejecutar: python app.py
Luego ingresar al navegador tocando el: http://127.0.0.1:5000

## Decisiones
1. En el Auxiliar 8 se utilizó Highcharts para construir gráficos, y dentro de la explicación se mostró cómo utilizar la IA de esta herramienta. Esto me dio a entender que también podía ocuparla para mi tarea, así que decidí utilizar Highcharts Assist para generar el código de los tres gráficos y adaptarlo a los datos de mi aplicación.

2. Decidí conservar la estructura y las funcionalidades de la Tarea 2, modificando solamente lo necesario para incorporar los gráficos y los comentarios. Así pude reutilizar gran parte del código que ya tenía implementado.

3. Para las validaciones del formulario de comentarios decidí reutilizar el estilo de los mensajes de error que había implementado en el registro de voluntarios de la Tarea 2, para mantener un diseño similar entre los formularios.
4. Ocupé .gitignore, ya que no necesitaba mandar el venv, esta parte la hice con apoyo de la ia.
